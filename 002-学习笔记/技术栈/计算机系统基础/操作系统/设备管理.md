> 回顾：操作系统的一大作用是底层硬件资源的管理者

# 什么是 I/O 设备

- IO设备：能从计算机中接收输出的数据（Output），能把数据输入到计算机中（Input）的设备
- 按照使用的特点分类
	- 人机交互式的：鼠标、键盘
	- 存储设备：硬盘
	- 网络设备：网卡、调制解调器
- 按照传输的数据单位划分
	- 块设备：磁盘，为块为单位进行数据的传输，可以随机寻址的设别
	- 字符设备：以字符为单位传输，传输效率慢，不可随机遵寻址，一般中断驱动

# CPU 处理器如何使用硬件资源-IO控制器

> cpu 无法直接和硬件打交道，计算机的世界中，加抽象层可以解决这种问题

IO控制器是什么：CPU和物理硬件的中间层，可以通过CPU指令，设置内部寄存器的值，再由IO逻辑单元根据寄存器的值，通过和设备的接口，调用设备
- cpu - io控制器接口（体现为寄存器的值）
	- 控制寄存器（接收识别cpu的命令）
	- 状态寄存器（向cpu报告设别的状态）
	- 数值寄存器（用于cpu和设备的数据交换）
	- 寄存器地址（IO控制器中，会给所有寄存器以地址的方式进行编号，地址寄存器可以定位具体的寄存器）
		- 内存映像 IO，是说寄存器的地址，是在物理内存地址最大值 N 之后继续编址；可以复用同一套内存地址，完成对使用设备的定位。
		- 寄存器独立编制：寄存器的地址，在每一个控制器中，都是从0重新开始编制，需要单独的命令来执行，效率高
- io 逻辑，处理cpu的命令，调用和设备的接口，完成任务
- io控制器 - 设备的接口
	- 一个 IO 控制器可以连接多个设备

# IO控制方式

> 程序如何通过向设备读写数据

1. 程序控制：由调用IO的程序主动查询IO情况（IO控制器中状态寄存器的值）；会使CPU轮询检查，利用率低
2. 中断驱动：程序发出IO调用后，进程阻塞、调度，后续IO设备完成后，通过中断告知cpu任务完成，将阻塞进程唤醒

> 这两种方式，区别在于设备执行阶段，CPU的利用效率。
> 中断驱动方式，引发进程调度，现在的非阻塞调用，就是通过内核态不阻塞，用户态通过虚拟线程调度或者协程状态机变换等方式，提高程序的执行效率
> 
> 但是相同的
> - 读取数据IO操作：数据准备好后，需要由 CPU 负责把数据从寄存器中读取，在写回到内存中
> - 读写的数据单位，都是字为单位，因为 CPU 的限制

 3.  DMA 方式：通过 DMA（直接内存访问设备），把数据从IO控制器中，直接写入到内存中，或者从内存中读取。CPU会在DMA开始传输数据和结束传输数据时间段干预。
	 cpu干预内容：告诉 DMA 数据在哪一个设备中，读取到内存的哪里，读取多少长度；DMA传输结束，通过中断告诉 CPU，然后cpu直接继续执行代码，不用搬运数据
	 数据读写的单位：**块**

# IO体系

- 用户IO软件
- 设备独立性程序：完成设别无关性的转换，从逻辑设备转到对物理设备的操作
- 设备驱动程序：把独立性程序抽象命令，转为IO控制器能看得懂的命令（**这里包含把文件的物理块地址，转换为磁盘的磁面、柱面、扇区地址**）
- 中断程序：有些IO方式涉及到中断处理

# 缓冲区

**IO设备的虚拟化逻辑：SPOOLing 技术**（假脱机）

> 脱机处理：指通过把原先输入给CPU的纸带，经过外围机处理，得到磁盘，从而让CPU能更快的读取输入数据

SPOOling 技术通过输入程序和输出程序，来模拟实现了外围机的作用，把字节设备的输入或者输出数据，放置在磁盘中，并把磁盘中这片区域称为输入井、输出井。
通过 SPOOLing 技术，可以把物理设备虚拟化，原来独占的物理设备，现在转为把数据写入输入输出井中就释放，而不用等到进程结束。独占设备变成逻辑上的共享设备

**CPU处理速度太快：缓冲区技术**

CPU的处理速度比IO处理速度快非常多，为了补足速度的差异，也为了让CPU减少处理数据的次数，补足处理数据单位的差异，可以在内存中设置缓冲区。

**进一步提高CPU和IO的并行：双缓冲区、缓冲池**

# 磁盘调度算法

**磁盘读写操作时间组成**：寻道时间+延迟时间（找到扇区）+传输时间
> 寻道时间是大头，调度算法的主要目的是减少寻道时间---**减少磁头移动距离**

1. FCFS
	- 平均寻道时间会比较
2. SSTF（最短寻道时间优先，Short Search Time First）：每一次移动到最近的磁道
	- 存在饥饿现象
	- 局部最优，不是全局最优
3. SCAN（扫描 / 电梯算法）
	- 磁头向一个方向一直移动，直到磁道的最外侧或者最里侧才能更换方向
	- 缺点：只有到两侧才能换方向，哪怕需要读取的最边上磁道位置不是最里侧或者最外侧
4. C-SCAN
	- SCAN 算法中，不同位置的磁道扫描到的频率不一样（比如当前处理了90号，往右移动，后面处理了180号，继续往右移动到200，回头，180马上又被扫描）
	- C-SCAN 算法规定，只有一个方向上的移动，能读取数据。磁头移动到一侧后，快速返回另一端
5. LOOK 算法
	SCAN算法存在的一个问题就是存在无效的移动距离，当前方向上没有要扫描的磁道，还要移动到头。
	LOOK 算法会边移动边检查，如果当前方向上，没有要读取的磁道，直接反向
