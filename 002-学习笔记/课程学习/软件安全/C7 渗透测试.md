# 信息搜集使用的一些技巧

## 被动信息搜索

> 被动指不直接和目标服务器交互，搜集相关信息

### 浏览器搜索引擎支持的查询方式

1. inurl：搜集 url 包含指令关键字的内容
2. intitle：网页标题要求包含
3. Site：只显示目标域名的相关所有结果
4. IP: 搜集目标IP上的网站

### whois

`whois 域名`：可以查到域名的注册商、电话、邮箱、地址、DNS 服务器地址

### host -t ns

`host -t ns 域名`：查询域名所在的服务器

## 主动信息搜集

> 通过 nmap 工具，搜集服务器内部的信息

1. `nmap -sP 网络地址` ： 网络内的存活主机，不探测端口
2. `nmap -p[端口范围] 主机IP` ：探测目标主机上指定端口范围中的开发情况
3. `nmap -O` : 对目标主机的系统以及版本探测
> 指纹探测就是对目标主机的系统版本、服务版本、以及目标站点所用的CMS版本进行探测
4. Web 指纹探测：探测WEB服务器的信息
5. Web 敏感目录扫描

## 简述渗透测试 PTES 七阶段，说明“报告阶段”的重要性

PTES 将渗透测试分为7个阶段，分别为：
1. 前期交互阶段：和客户确认测试范围、目标、限制条件、授权和合同细节
2. 情报搜集阶段：搜集目标组织、域名、网络、系统、人员、服务等信息
3. 威胁建模阶段：基于搜集到的信息分析可能的攻击面，规划攻击路径
4. 漏洞分析阶段：分析目标系统可能存在的漏洞，并验证可利用性
5. 渗透攻击阶段：利用漏洞获取访问控制权限或证明风险存在
6. 后渗透攻击阶段：在**授权范围内**进一步分析影响，比如权限提升、横向移动、敏感信息获取等
7. 报告阶段：整理测试过程、发现的问题、攻击路径、影响分析和修复建议

报告阶段的重要性在于，渗透测试的最终目的不是“攻击成功”，而是帮助被测方理解风险并改进安全体系。高质量的报告应该包含漏洞证据、复现条件、影响范围、风险等级和加固方案，使管理人员和技术人员都能据此采取行动。
